# ESUT NOTEBOOK APP MINI PROJECT

## Overview
The ESUT Notebook App is a user-friendly web-based application that allows users to efficiently create, write, edit, organize, and delete personal notes. This mini project was developed as a collaborative effort to demonstrate proficiency in full-stack web development using vanilla JavaScript and modern web technologies.

## 🎯 Project Features

- **Create Notes**: Quickly add new notes with a title and content

## 📋 How to Use

### Getting Started
1. Open the `index.html` file in your web browser
2. You'll see the Notebook App interface with a header and search bar

### Creating a Note
1. Click the **"Add New Note"** button in the header
2. Enter a title (optional) and content for your note
3. Click **"Save Note"** to store it
4. Your note will appear in the notes list

### Editing a Note
1. Click the **"Edit"** button on the note you want to modify
2. Update the title and/or content in the form
3. Click **"Save Note"** to apply changes

### Deleting a Note
1. Click the **"Delete"** button on the note you wish to remove
2. Confirm the deletion when prompted

### Searching Notes
1. Use the search box at the top to filter notes by keyword
2. Notes matching your search term will be displayed instantly
3. Clear the search box to view all notes

## 💾 Data Storage

- All notes are stored in the browser's **localStorage**
- Data persists even after closing and reopening the browser
- Each note includes a title, content, and timestamp
- Maximum storage depends on browser settings (typically 5-10MB)
